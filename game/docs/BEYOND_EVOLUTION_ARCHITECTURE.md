## Eight compatibility requirements
1. Mutable universe: preserve canonical G20 50 systems/seven regions as starting catalog; add runtime entities with stable IDs, parent relationships, ownership, lifecycle, location and tombstones. No rewriting canonical IDs; configurable capacity.
2. Persistent planet state: versioned atmosphere/climate/hydrology/geology/biosphere, infrastructure, military, underground and orbital layers. Regional terrain patches derive from authoritative state; preserve existing structures and occupants or explicitly resolve conflicts, never silently regenerate them. Validate navigation and cross-layer consistency.
3. Runtime species/faction registries: separate authored immutable definitions from versioned generated definitions; seed, generator version, parent IDs, modular assets and validated production/doctrine graphs. No external AI dependency.
4. Shared project framework: objective, site, owner, authority, prerequisites, dependencies, phases, work, material/energy reservations, assigned fleet, operational/damage state. Atomic reserve/commit/release; deterministic cancellation and takeover; no free resources.
5. Save migration: versioned schemas, stable references, generated definitions, ledger/checkpoints, RNG and scheduler state; migrate copies, preserve original saves, validate references and conservation. Missing entitlement must not silently delete content; explicit compatible read-only/restore policy before release.
6. Hierarchical simulation: active tactical full fidelity; active region detailed; planet aggregated; system strategic; distant civilizations/ecosystems event-driven. Bounded queues, deterministic ordering, promotion/demotion reconciliation of units, losses, resources, history and construction. Profile CPU, memory, save size, latency and worst-case transitions; no unsupported scale claims.
7. Multi-timescale scheduler: tactical ticks and deterministic strategic epochs; bounded catch-up, no duplicate work, no free resources, no skipped critical military consequences. Technology and capacity accelerate projects; avoid mandatory idle waiting.
8. Generated content validation: schema, references, compatibility, production reachability, navigation, ecology, ownership, entitlement, asset budgets and version compatibility. Declarative imports only, sandbox preview, reject invalid packages safely.
## Integration boundaries
Godot owns presentation/input; authoritative simulation owns state and commands; Rust acceleration chosen by profiling, preserve native/fallback parity. Extend UNDERSTRIKE for engineered interiors only where existing rules allow. World Archive owns history/lineage; Operational Intelligence owns actionable reports; Dynamic Scenario Engine derives operations; Workshop handles declarative templates; Myrieme Forge provides versioned offline language packages. No duplicated authoritative state.
