## Intelligent world generator
Reusable deterministic, constraint-based generator for actual usable RTS geography, functional settlements and military installations, not decorative random scattering. Separate from scenario rules; uses existing map, navigation, geometry, ledger and faction systems. Authored macro geography and campaign canon preserved; generated variants use permitted masks. Generated world may have a coherent initial history explicitly marked authored/generated backstory, not falsely played events. No new universe count, stage or factions. DLC adapters only after entitlement and appropriate gates.

Pipeline: seed/version + climate/biome/topology -> terrain/water/elevation/land suitability -> movement graph and crossings -> resource distribution -> roads/rail/ports/airfields/settlement centers -> industrial and utility networks -> faction/stage-legal bases and defenses -> environment/ruins/history -> validation and bounded repair/retry. Terrain, buildings, resource placement and routes obey actual dimensions/clearance; no scaling down large facilities to fit. City layout follows plausible routes, land use, logistics and public/military infrastructure, zoning where supported. Generated history explains visible ruins, development and site conditions without inventing canon. Underground uses existing chunk geology, supports, clearance, surface links, groundwater, protected Human A rights and existing unlocks. Other factions may occupy pre-existing legal assets, never generate new prohibited construction. Exact terrain/route design is game abstraction, performance budget measured.

Candidate input {seed, generator_version, biome, scale, allowed_stage, faction_capabilities, role, site_budget, authored_masks, environmental_rules, available_assets}; output {world_ref, graph_refs, topology_hash, placed_assets, resource_ledger_initialization, provenance, validation_report}. Check reachable spawns/objectives, movement classes, crossing capacity, transport clearance, resource access, power/storage and production prerequisites, safe exits, no overlaps, valid height/geology, scenario-specific counterplay and expected performance. Bounded retries; fail clearly or fall back to verified preset with user approval. Faction-specific fortress grammar defined in [SIEGE WARFARE](SIEGE_WARFARE_GDD.md). Adaptive AI development uses real construction/repair through normal ledger, not free generated assets mid-match. World seeds reproducible within generator version and manifest; persist actual world geometry rather than regenerating on load.

## Universal engineering templates
Save functional player-designed outposts, HQs, military compounds, defense networks, aviation complexes, ports, dockyards, industrial plants, underground facilities, civilian settlements and compatible future space colonies/stations. Template {id, schema, content_manifest, faction/stage constraints, dimensions, modules, connections, orientation, optional modules, resource requirements, clearance, terrain constraints, owner/provenance}. Distinguish template geometry from actual assets: import never grants free construction, prohibited faction tech or unowned content. Fit to terrain by eligible rotations/translations and optional validated adaptations; show preview, cost, requirements, conflicts and alternatives. Major layout changes ask approval; no fake vehicle access or decorative fake doors. User chooses place/build/expand, engineers reserve resources, construct by dependency order, route supplies, repair and report blocked reasons. One-click order with optional manual placement, pause/cancel, no repetitive worker commands. Preserve actual occupancy and existing player structures; no destructive replacement without explicit approval.

Template placement algorithm (illustrative): enumerate bounded candidate sites -> evaluate legal capability, footprint, access, stability, clearance, utility/logistics links -> rank feasible choices -> preview -> validate atomic reservation -> create ordered build tasks -> commit as normal construction. Saved partial builds and pending orders survive reload. Template and blueprint packages versioned, validated, locally exportable, shareable through Workshop. Equipment/formation loadout templates optional for selected legal categories; modernization order from Operational Intelligence validates tech/tooling/materials/time and refit or replacement, transfers old equipment lawfully. No vehicle CAD simulator or mandatory component customization. G11 template foundation, G13 industrial/fortress layout, G16 mature underground generation, G17 world integration, G18 editor/Workshop. Tests deterministic seeds, route/clearance, faction rights including capture/editor/mod, stage and ownership, real material consumption, cancellation, persistence, safe adaptation and generated map playability.
